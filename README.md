# Cosmetic Risk Detector

End-to-end data science project to detect risky cosmetic products from their INCI ingredient list.

## Context

Thousands of cosmetics are sold on the French market. Neither consumers nor e-commerce platforms can easily check whether a product contains substances banned or restricted under European regulation.

This project builds a machine learning classifier that predicts, from a product's INCI ingredient list alone, whether it contains a risky ingredient.

## Data Sources

- **Open Beauty Facts** — open cosmetics database (products + INCI lists)
- **ECHA Annexes II & III** — official EU lists of prohibited and restricted substances
- **CosIng** — European Commission ingredient database
